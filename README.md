# web_2048
2048 Game | University Web Development Project 

# Описание
Репозиторий содержит код для создания игры 2048

# Функциональность
Пользователь может:
1. Взаимодействовать с игровым полем
2. Записать свой рекорд в таблицу лидеров в случае окончания игры
3. Просмотреть список лидеров
4. Продолжить игровую сессию с последнего действия
5. Вернуться на один шаг назад
6. Начать игру заново

Игра завершается при невозможности совершить движение плиток в любую из 4х сторон

# Макет страницы
1. В HTML файле содержится только базовый каркас страницы и статические элементы (кнопки и виртуальные кнопки для игры на мобильных устройствах)
2.  Все элементы создаются через DOM API
3. Используются семантические теги

# Макет страницы
Для выполнения были использованы чистые HTML, CSS, JavaScript. Без использования фреймворков. Также с помомощью Google Fonts был добавлен шрифт Outfit.

# Адаптивность
ToDo-лист адаптирован под различные устройства и корректно отображается на ноутбуках, планшетах и телефонах.

# Note
В инструментах разработчика браузера (инспекторе) при изменении типа устройства (эмуляция мобильного/десктопа) кнопки не появляются автоматически - требуется перезагрузка страницы для обновления состояния виртуальных кнопок. Непосредственно на самих устройствах все работает корректно (то есть если открыть деплой на телефоне, а не в инспекторе, кнопки управления появятся после нажатия на "New Game", в случае если это первичный запуск игры, и при дальнейших открытиях игры пропадать не будут)
